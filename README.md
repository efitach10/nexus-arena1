# Nexus Arena

אבטיפוס בעברית לפלטפורמת טורנירי גיימינג, עם תמיכה ב־PWA.

## צפייה

https://efitach10.github.io/nexus-arena1/

## התקנה

באייפון ובאייפד: פותחים ב־Safari, בוחרים שיתוף ואז הוסף למסך הבית. אם מוצגת האפשרות פתיחה כיישום אינטרנט, יש להפעיל אותה.

בדפדפנים תומכים אפשר להשתמש בכפתור ההתקנה באתר. אם לא מוצגת הצעת התקנה, הכפתור יציג הוראות להתקנה דרך הדפדפן.

## שימוש ללא אינטרנט

לאחר שהאתר נטען בהצלחה וה־Service Worker השלים התקנה, הממשק ונתוני הדוגמה זמינים גם ללא אינטרנט. השינויים נשמרים בדפדפן באמצעות localStorage. אין שרת, סנכרון בין מכשירים או מערכת משתמשים אמיתית.

## קבצים

- index.html — מסמך הכניסה וקישורי ה־PWA.
- app.js ו־style.css — מסכי האבטיפוס והעיצוב.
- manifest.webmanifest ו־icons/ — הגדרות התקנה ואייקונים.
- pwa.js ו־pwa.css — התקנה, הנחיות ומצב ללא אינטרנט.
- sw.js — מטמון מקומי המוגבל לנתיב הפרויקט.

## עדכונים

כאשר משנים קבצים שנשמרים במטמון, יש לשנות גם את VERSION בתוך sw.js. גרסה חדשה מותקנת ברקע; כאשר היא מוכנה, האפליקציה מציעה לעדכן. הפרסום מתבצע מ־main ומתיקיית השורש באמצעות GitHub Pages.

כל השחקנים, התחרויות, התוצאות והפרסים הם נתוני הדגמה.
